Project page

Detecting anomalous smart-meter readings: a model × split comparison

Four classical machine-learning models are trained and evaluated on the LEAD commercial-building dataset across five train/test splits. Hyperparameters are tuned separately inside each training portion and every result is measured on untouched test data.

Task 02

What the models are asked to detect

Each building reports one electricity reading per hour, and each reading is labelled normal or anomalous. The task is binary classification of single readings. Select a type to see the kind of deviation involved, drawn on a typical weekly profile.

Dataset 03

LEAD: hourly readings from 200 buildings

Class balance

500 readings drawn to scale; anomalies in red.

input features

Building metadata, weather, calendar encodings and each building's typical consumption level come from the competition's feature file. Six engineered features (highlighted) express how far a reading is from its own building's typical level. The building identifier and composite keys derived from it are removed.

Evaluation 04

How the models are scored

Choose a classifier and a split. The confusion matrix and metrics are the real test-set counts. The majority-class baseline predicts "normal" for every reading and shows why accuracy alone is not used to rank the models.
